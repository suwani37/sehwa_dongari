# Tetris

Windows PC에서 즐기는 테트리스 게임입니다. 혼자 기록에 도전하거나 AI와 쓰레기 줄을 주고받으며 대결할 수 있습니다. 한국어와 영어를 지원합니다.

**바로 플레이하기: [Tetris.exe 다운로드](dist/Tetris.exe)**

## 1. 다운로드하고 실행하기

배포된 EXE는 **Windows 64비트용**입니다. Python이나 Pygame을 설치하지 않아도 됩니다.

1. 위의 **Tetris.exe 다운로드** 링크를 엽니다.
2. GitHub의 파일 보기 화면이 열리면 다운로드 버튼으로 `Tetris.exe`를 저장합니다. 저장소 전체를 ZIP으로 받았다면 압축을 풀고 `dist` 폴더를 여세요.
3. 저장한 **Tetris.exe를 더블클릭**합니다. 터미널에 명령을 입력할 필요가 없습니다.
4. 메인 화면에서 **PLAY → 원하는 모드**를 선택합니다.

게임을 플레이할 때는 **Tetris.exe 하나만 있으면 됩니다.** 코드 파일과 assets 폴더를 따로 받을 필요가 없으며, AI 배틀도 인터넷 연결 없이 플레이합니다.

### 한국어로 바꾸기

처음 실행하면 메뉴가 영어로 표시됩니다. **SETTING → TIMING → English / 한국어**를 눌러 한국어로 바꾸세요. **뒤로** 버튼으로 메인 화면에 돌아올 수 있습니다. 언어와 단축키·속도 설정은 자동 저장됩니다.

## 2. 기본 조작법

| 기능 | 기본 키 | 설명 |
| --- | --- | --- |
| 왼쪽 / 오른쪽 이동 | ← / → | 누르고 있으면 해당 방향으로 반복 이동합니다. |
| 소프트 드롭 | ↓ | 누르고 있는 동안 조각을 빠르게 내립니다. |
| 하드 드롭 | Space | 고스트 위치로 즉시 내려놓고 고정합니다. |
| 시계 방향 회전 | ↑ 또는 X | 조각을 오른쪽으로 90도 회전합니다. |
| 반시계 방향 회전 | Z | 조각을 왼쪽으로 90도 회전합니다. |
| 홀드 | C 또는 왼쪽 Shift | 현재 조각을 보관하거나 보관한 조각과 교환합니다. |
| 일시정지 / 계속하기 | Esc 또는 P | 일시정지 화면을 열거나 게임을 계속합니다. |
| 게임 종료 | Q | 플레이 중 프로그램을 종료합니다. |

위 표는 기본값입니다. **SETTING → KEYS**에서 원하는 키로 바꿀 수 있습니다.

메뉴는 **마우스 클릭** 또는 **↑ / ↓와 Enter**로 선택합니다. 튜토리얼에서는 **← / →**로 페이지를 넘기고 **Esc**로 돌아갑니다.

**게임 종료·완료 결과 화면은 마우스로만 조작합니다.** 다시 시작하려면 **RETRY / 다시 시작** 버튼을 클릭하세요. 결과 화면에서는 Space, Enter, R, Esc 등 키보드 입력이 작동하지 않습니다.

## 3. 처음 플레이한다면

떨어지는 조각을 좌우로 옮기고 회전시켜 빈틈없이 쌓으세요. 가로 한 줄의 10칸을 모두 채우면 그 줄이 사라집니다. 다음 조각이 나올 자리가 막히면 게임 오버입니다.

- **고스트:** 현재 조각 아래의 반투명 표시입니다. Space를 눌렀을 때 조각이 놓일 위치를 보여 줍니다.
- **HOLD / 홀드:** 조각을 잠시 보관하는 칸입니다. 한 조각을 고정하기 전에는 한 번만 사용할 수 있습니다. 새 조각을 놓으면 다시 사용할 수 있습니다.
- **NEXT / 다음:** 앞으로 나올 조각 다섯 개를 보여 줍니다.
- **줄 삭제 알림:** 홀드 칸 아래에 싱글·더블·트리플·테트리스·T스핀 등의 삭제 방식을 표시합니다. 보드를 완전히 비우면 퍼펙트 클리어 효과와 추가 점수를 얻습니다.

한 번에 1줄은 **싱글**, 2줄은 **더블**, 3줄은 **트리플**, 4줄은 **테트리스**입니다. 줄 삭제에는 약 0.2초의 효과 시간이 있습니다.

## 4. 게임 모드

메인 화면에서 **PLAY / 플레이**를 선택하면 모드를 고를 수 있습니다.

| 모드 | 플레이 방법 | 목표 |
| --- | --- | --- |
| **40 LINE / 40줄** | 40줄 이상을 지우면 완료됩니다. 마지막 줄 삭제 효과가 끝나면 기록이 멈춥니다. | 최대한 짧은 시간에 완료하기 |
| **BLITZ / 블리츠** | 120초 동안 플레이합니다. 시간이 끝나면 결과가 표시됩니다. | 제한 시간 안에 높은 점수 얻기 |
| **MARATHON / 마라톤** | 시간 제한 없이 플레이하며, 10줄마다 레벨과 자연 낙하 속도가 올라갑니다. | 오래 살아남으며 점수 올리기 |
| **AI BATTLE / AI 배틀** | 난이도를 선택하고 AI와 대결합니다. 먼저 보드가 막히는 쪽이 패배합니다. | AI보다 오래 살아남기 |

목표를 달성하기 전에 보드가 막히면 해당 게임은 게임 오버로 끝납니다.

## 5. AI 배틀

**PLAY → AI BATTLE → EASY / NORMAL / HARD** 순서로 시작합니다. 왼쪽 보드는 플레이어, 오른쪽 보드는 AI입니다.

| 난이도 | 특징 |
| --- | --- |
| **EASY / 쉬움** | 조각을 천천히 놓으며 배치 판단에 빈틈이 있습니다. |
| **NORMAL / 보통** | 여러 줄을 모아 지우고 홀드 조각을 활용해 공격합니다. |
| **HARD / 어려움** | 보통보다 빠르게 조각을 놓고 공격에 더 높은 우선순위를 둡니다. |

여러 줄 삭제나 T스핀 등으로 **쓰레기 줄**을 상대에게 보냅니다. 쓰레기 줄은 구멍이 있는 블록 줄로, 상대 보드 아래에서 올라옵니다. 양쪽은 같은 조각 순서로 시작하며 공격 규칙도 같습니다.

- 자신의 대기 공격이 있으면 공격으로 먼저 상쇄하고, 남은 양을 상대에게 보냅니다.
- 받은 공격은 **1초 동안 예고**됩니다. 이후 줄을 지우지 않은 조각을 놓을 때 **최대 4줄씩** 올라옵니다. 남은 공격은 대기합니다.
- 보드 옆의 대기 공격 막대는 예고 중에는 **노란색**, 올라올 수 있는 상태에서는 **빨간색**입니다.
- 쓰레기 줄에 밀려 블록이 보드 위로 넘치거나 다음 조각이 나올 자리가 막히면 패배합니다. 양쪽이 동시에 패배하면 무승부입니다.
- 일시정지하면 AI와 공격 대기 시간도 함께 멈춥니다.

<details>
<summary>자세한 공격량 보기</summary>

| 삭제 방식 | 보내는 쓰레기 줄 |
| --- | --- |
| 싱글 / 더블 / 트리플 / 테트리스 | 0 / 1 / 2 / 4줄 |
| T스핀 미니 싱글 / 더블 | 1 / 2줄 |
| T스핀 싱글 / 더블 / 트리플 | 2 / 4 / 6줄 |
| 퍼펙트 클리어 | 총 10줄 고정, 다른 공격 보너스와 중복하지 않음 |

**백투백:** 테트리스나 줄을 지운 T스핀·미니를 연이어 성공하면 두 번째부터 1줄을 추가합니다. 줄을 지우지 않은 조각은 백투백을 유지하지만, 일반 싱글·더블·트리플은 끊습니다.

**콤보:** 조각을 놓을 때마다 연속으로 줄을 지우면 추가 공격을 얻습니다. 줄을 지우지 않은 조각을 놓으면 콤보가 초기화됩니다.

| 연속 줄 삭제 횟수 | 콤보 추가 공격 |
| --- | --- |
| 1~2회 | 0줄 |
| 3~5회 | 1줄 |
| 6~9회 | 2줄 |
| 10회 이상 | 3줄 |

줄을 지우지 않은 T스핀은 공격을 보내지 않습니다. 화면의 **보낸 줄**은 상쇄 후 상대에게 실제로 보낸 양이고, **받은 줄**은 자기 보드에 실제로 올라온 양입니다.

</details>

## 6. 설정 바꾸기

메인 화면의 **SETTING / 설정**에서 바꿀 수 있습니다. 플레이 중에도 일시정지한 뒤 설정에 들어갈 수 있습니다.

### 속도와 언어 — TIMING / 속도

| 항목 | 기본값 | 의미 |
| --- | --- | --- |
| **DAS** | 12프레임 / 200ms | 방향키를 계속 누를 때 반복 이동이 시작되기까지의 대기 시간입니다. |
| **ARR** | 2프레임 / 약 33.333ms | 반복 이동 사이의 간격입니다. 0이면 DAS 이후 벽까지 즉시 이동합니다. |
| **SOFT DROP / 소프트 드롭** | 50ms | ↓를 누르고 있을 때 한 칸 내려가는 간격입니다. |
| **LOCK DELAY / 착지 후 고정 시간** | 300ms | 착지한 조각이 고정되기까지의 시간입니다. |
| **LANGUAGE / 언어** | English | 영어와 한국어를 선택합니다. |

프레임은 60FPS 기준이며, **1프레임은 약 16.67ms**입니다. 값 옆의 **− / +** 버튼으로 조절합니다.

### 단축키 — KEYS / 단축키

1. 바꿀 기능의 키 칸을 클릭합니다. 기능마다 최대 **두 개**의 키를 지정할 수 있습니다.
2. 사용할 키를 누릅니다. 이미 다른 기능에 지정된 키는 중복 지정할 수 없습니다.
3. 키를 없애려면 지정 중 **Delete / Backspace**, 취소하려면 **Esc**를 누릅니다.

일시정지 키는 하나 이상 남겨야 합니다. 키보드로 설정할 때는 **Tab**으로 탭 전환, **↑ / ↓**로 항목 선택, **← / →**로 값 또는 키 칸 선택, **Enter**로 키 지정을 시작합니다.

**RESET DEFAULTS / 기본값 복원**은 현재 탭의 속도 값 또는 단축키를 기본값으로 돌립니다. 설정은 자동 저장되므로 다음 실행에도 유지됩니다.

## 7. 일시정지·다시 시작·종료

- **Esc / P:** 일시정지합니다. **RESUME / 계속하기** 또는 일시정지 키로 이어서 플레이합니다.
- **일시정지 → 설정 / 튜토리얼:** 게임 시간을 멈춘 상태로 확인할 수 있습니다. 돌아오면 일시정지 화면으로 복귀합니다.
- **MAIN MENU / 메인 화면:** 진행 중인 게임을 끝내고 메인 화면으로 돌아갑니다. 다시 PLAY를 누르면 새 게임을 시작합니다.
- **결과 화면 → RETRY / 다시 시작:** 마우스로 클릭하면 같은 모드로 새 게임을 시작합니다. AI 배틀은 선택한 난이도를 유지합니다.
- **QUIT / 종료:** 메인 화면에서 선택합니다. 게임 중에는 기본 키 **Q**, 또는 창의 닫기 버튼으로 종료할 수 있습니다.

다른 창으로 전환하면 게임은 자동으로 일시정지됩니다.

## 8. 자주 묻는 질문

**창이 크거나 작아요.**  
창 가장자리나 모서리를 드래그해 크기를 바꾸세요. 화면 비율을 유지하며 남는 공간에는 여백이 생깁니다. 글자는 창 크기에 맞춰 그립니다.

**Space를 눌러도 결과 화면에서 다시 시작되지 않아요.**  
의도된 동작입니다. 하드 드롭 도중 실수로 새 게임이 시작되지 않도록 결과 화면은 마우스로만 조작합니다.

**조작키가 설명과 달라요.**  
이전에 저장한 설정이 적용되었을 수 있습니다. **설정 → 단축키 → 기본값 복원**으로 위 표의 기본 조작을 복원하세요.

**다른 사람에게 어떤 파일을 전달해야 하나요?**  
`dist/Tetris.exe` 하나면 됩니다. 설정은 각 PC에 따로 저장되며, EXE를 새 버전으로 바꿔도 기존 설정을 불러옵니다.

<summary>개발자용: 소스 실행·검사·EXE 빌드</summary>

플레이만 한다면 이 과정은 필요하지 않습니다. 현재 개발 환경은 **Python 3.13**이며, 아래 명령은 프로젝트 폴더에서 PowerShell로 실행합니다.

### 소스로 실행

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

소스로 실행할 때는 `main.py`, `tetris/`, `assets/` 등 프로젝트 파일을 함께 유지하세요.

### 자동 검사와 EXE 빌드

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\build_exe.bat
```

검사는 게임 규칙·입력·설정·화면 그리기를 검사하며 게임 창이나 EXE를 실행하지 않습니다. 빌드 결과는 `dist/Tetris.exe`입니다. 게임을 수정했다면 배포 전에 EXE를 다시 빌드하세요.

설정 저장 위치:

- EXE 실행: `%LOCALAPPDATA%\SuwanTetris\player_settings.json`
- 소스 실행: 프로젝트 폴더의 `player_settings.json`
